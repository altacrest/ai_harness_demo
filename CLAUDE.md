## Working rules

- `main` is closed: before each code change, ask whether to use a new branch
  or unlock `main`. Never branch alone.
- Para cualquier trabajo de UI (diseño, revisión, pulido, accesibilidad visual)
  usa la skill impeccable y respeta PRODUCT.md y DESIGN.md; no uses design.
- Ignore generated outputs: `node_modules/`, `dist/`, `.astro/`.
- Never publish secrets: `.env`, `01-TOOLS/**/.env`, `CREDENTIALS.md`, tokens.
- Documentation goes through the wiki protocol: new sources in
  `02-DOCS/inbox/` or `raw/<topic>/`, distilled knowledge in `wiki/<topic>/`,
  index and log kept current.

## Main commands

```bash
npm install          # dependencies
astro dev --background   # dev server (stop/status/logs: astro dev stop|status|logs)
npm run build        # production build to dist/
npm run preview      # preview the build
```
